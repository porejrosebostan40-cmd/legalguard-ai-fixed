# LegalGuard AI — Карманный адвокат

Чистая реализация системы анализа судебных актов и подготовки апелляционных/кассационных жалоб.

## Архитектура

Судебные материалы → DeepSeek (первичный поиск) → ChatGPT Арбитр → ChatGPT Стратег → ChatGPT Финальный контроль → итоговый документ.

Принцип: DeepSeek ищет максимально широко; ChatGPT оценивает юридическую значимость, отбрасывает шум, строит стратегию и выполняет финальную проверку. Отклонённые основания не могут попасть в итоговый документ.

## Этапы

1. Приём и нормализация судебных материалов.
2. Первичный анализ DeepSeek.
3. Арбитраж ChatGPT: принять / отклонить / на проверку.
4. Построение правовой стратегии.
5. Финальный контроль: основания, ссылки, процессуальная форма, отсутствие отклонённых аргументов.
6. Формирование итоговой жалобы.

## Принцип трассировки

Каждое основание проходит цепочку:

`ФАКТ → НАХОДКА DEEPSEEK → РЕШЕНИЕ АРБИТРА → СТРАТЕГИЯ → ФИНАЛЬНЫЙ ТЕКСТ`

Каждый запуск получает идентификатор вида `LG-ГГГГММДД-XXXX`.

## Жёсткие инварианты

- Отклонённое основание не попадает в финальный документ.
- `needs_review` блокирует готовность документа к подаче.
- Неизвестные и дублирующиеся идентификаторы оснований блокируют финальный контроль.
- Финальный контроль обязателен.
- Секретные API-ключи не хранятся в браузерном коде.
- Провайдеры ИИ изолированы от юридического ядра.
