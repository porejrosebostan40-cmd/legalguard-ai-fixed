# LegalGuard AI — карманный помощник для работы с судебными материалами

MVP для контролируемого анализа судебных актов и подготовки черновиков апелляционных и кассационных жалоб.

## Текущее состояние

- Интерфейс React + TypeScript.
- Извлечение текста из TXT, текстовых PDF и DOCX. Сканированные PDF пока требуют OCR и не обрабатываются.
- Тестовый провайдер с демонстрационными результатами.
- Адаптер локальных моделей с OpenAI-совместимым API; адрес ограничен `localhost`, `127.0.0.1` и `::1`, имя модели задаётся в интерфейсе.
- Проект не требует API-ключей и не содержит вызовов облачных ИИ API в рабочем конвейере.
- Результат всегда считается черновиком: прохождение структурного контроля не означает юридическую точность или готовность к подаче.

## Архитектура конвейера

Судебный материал → первичный анализ → арбитраж находок → стратегия → структурный контроль → черновик.

Провайдеры отделены от юридического ядра через интерфейс `AIProviderSet`. Локальный адаптер отправляет запросы только на loopback-адрес, где пользователь должен заранее запустить совместимый с OpenAI локальный inference-сервер. Сам движок инференса и веса модели в репозиторий не входят. Тестовый провайдер использует демонстрационные данные. Облачные API и серверные ключи не входят в рабочий конвейер.

## Жёсткие инварианты

- Отклонённое основание не попадает в стратегию.
- `pending` и `needs_review` блокируют прохождение структурного контроля.
- Неизвестные и повторяющиеся идентификаторы оснований блокируют контроль.
- Секретные ключи не должны попадать в браузерный код.
- Успешная сборка и структурный контроль не являются юридическим заключением.
- Перед использованием черновика человек обязан проверить цитаты по первоисточнику, фактические выводы, действующие нормы, сроки и процессуальные требования.

## Локальная модель на Android

Инструкция по запуску локального inference-сервера через Termux: [docs/local-model-android.md](docs/local-model-android.md). Скрипт запуска llama.cpp: `scripts/run-local-llama-server.sh`. Сам движок и файл модели не входят в репозиторий.

## Локальная разработка

Требуется Node.js 20 или совместимая актуальная версия.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

GitHub Actions устанавливает зависимости, выполняет TypeScript/production-сборку и запускает тесты юридических инвариантов. Доступ к облачным API и платные секреты для CI не нужны.
