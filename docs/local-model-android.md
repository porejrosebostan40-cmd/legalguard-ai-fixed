# LegalGuard AI на Android: локальная модель

Локальный режим работает через `llama.cpp` и не требует ключей OpenAI/DeepSeek. Движок и веса модели не включены в репозиторий: их нужно один раз подготовить на устройстве. Выполнение и скорость зависят от процессора, свободной памяти и места на накопителе.

## Быстрый запуск

В Termux сначала установите Git и получите проект:

```bash
pkg update
pkg install git
git clone -b development/core-pipeline https://github.com/porejrosebostan40-cmd/legalguard-ai-fixed.git
cd legalguard-ai-fixed
```

Запустите сценарий подготовки:

```bash
bash scripts/setup-legalguard-android.sh
```

Сценарий установит зависимости, загрузит исходники `llama.cpp`, соберёт `llama-server`, установит зависимости приложения и предложит скачать модель. Сборка может занять продолжительное время; если она прервётся из-за нехватки памяти, не увеличивайте число потоков. Подготовке понадобится несколько гигабайт свободного места.

По запросу сценария можно скачать **Qwen3-1.7B-GGUF Q4_K_M** из репозитория `ggml-org` на Hugging Face. Размер файла около 1,28 GB. Это небольшая модель для первого теста конвейера, а не надёжный юридический эксперт; все выводы нужно перепроверять. Карточка модели и сведения о лицензии: https://huggingface.co/ggml-org/Qwen3-1.7B-GGUF. Загрузка модели требует достаточного места и мобильного трафика.

## Запуск

После завершения подготовки запустите оба компонента одной командой:

```bash
bash scripts/start-legalguard-android.sh
```

Сценарий запустит модель на `127.0.0.1:8080`, дождётся ответа `/v1/models`, затем запустит интерфейс и покажет адрес `http://127.0.0.1:5173`. Откройте этот адрес в браузере на том же телефоне. Нажатие `Ctrl+C` в Termux останавливает оба процесса. Журналы находятся в `~/.legalguard-ai/logs/`.

В приложении выберите **Локальная модель**. Значения по умолчанию:

- адрес: `http://127.0.0.1:8080/v1/chat/completions`
- имя модели: `local-model`

Нажмите **Проверить подключение**. Проверка обращается к локальному `/v1/models` и сообщает, отвечает ли сервер. Затем можно запускать анализ.

Не открывайте модельный сервер в локальную сеть или интернет. Не используйте для локального режима HTTPS-страницу GitHub Pages: браузер может заблокировать HTTP-запросы к localhost как смешанный контент. Открывайте локальный адрес Vite из Termux.

## Ручная настройка

Если подготовка выполняется вручную, установите `git cmake clang make nodejs-lts curl`, соберите `llama.cpp`:

```bash
git clone https://github.com/ggml-org/llama.cpp "$HOME/llama.cpp"
cmake -S "$HOME/llama.cpp" -B "$HOME/llama.cpp/build" -DGGML_OPENMP=ON -DGGML_NATIVE=OFF
cmake --build "$HOME/llama.cpp/build" --target llama-server -j 2
mkdir -p "$HOME/models"
```

Поместите совместимую GGUF-модель в `$HOME/models/model.gguf`. Для другого пути задайте `MODEL_PATH`. Можно запускать модель отдельно через `bash scripts/run-local-llama-server.sh`, а интерфейс — через `npm install` и `npm run dev -- --host 127.0.0.1`.

## Ограничения

- Сборка интерфейса и автоматические тесты не доказывают, что конкретная модель запустится на телефоне.
- Если модель не запускается или Android закрывает процесс, выберите меньшую модель или уменьшите контекст через `CTX_SIZE`.
- Сканированные PDF пока не поддерживаются: доступно извлечение текста из TXT, текстовых PDF и DOCX.
- Контроль цитат подтверждает только наличие текста в источнике, но не правильность юридического толкования.
- Приложение формирует черновик доводов, а не готовую к подаче жалобу. Проверяйте факты, первоисточники, нормы права, судебную практику, сроки и процессуальную форму.
