# Серверный шлюз LegalGuard

`server/handler.ts` содержит независимый Web API-обработчик. Он не хранит ключи в браузере: ключи передаются серверу через переменные окружения.

Маршруты:

- `POST /api/deepseek/analyze` — DeepSeek формирует первичные находки.
- `POST /api/chatgpt/arbitrate` — ChatGPT проверяет находки и принимает/отклоняет их.

Переменные окружения:

```text
DEEPSEEK_API_KEY=...
OPENAI_API_KEY=...
DEEPSEEK_MODEL=deepseek-v4-pro
OPENAI_MODEL=gpt-5
```

Секреты нельзя помещать в `VITE_*`, исходный код или клиентский JavaScript.

Обработчик рассчитан на серверные среды, поддерживающие стандартные `Request`, `Response` и `fetch`. Конкретный адаптер для Vercel/Cloudflare/Node можно добавить без изменения ядра LegalGuard.

Если ключ не задан или провайдер возвращает ошибку, запрос останавливается. Тестовые провайдеры остаются доступными без ключей.
